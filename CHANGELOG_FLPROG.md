# История изменений FLProg RTC STM32

## 1.0.1 — 2026-11-12

- Исправлен порядок настройки часов: до вычисления предделителей выбирается реальный LSE/LSI/HSE.
- Убрана запись в 32-битные поля структур HAL через указатели на 8- и 16-битные типы.
- Исправлена инициализация входных структур HAL и семантика DayLightSaving/StoreOperation.
- Для STM32 не-F1 после чтения времени добавлено чтение даты для разблокировки shadow registers.
- Добавлена проверка результатов HAL и защита неполных чтений и некорректных subSeconds.
- Улучшен подбор предделителя RTC и обработка недопустимого делителя HSE.
- Исправлена проверка макроса асинхронного предделителя и общий header guard.
- Дополнена русская документация, комментарии к публичному API и `keywords.txt`.
- STM32 HAL, RT_HW и интерфейс `Flprog_RTC` **не изменялись**.
